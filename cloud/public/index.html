SLG FieldTrack

The Android app for SLG field staff and supervisors. Staff share their location while on duty; supervisors see the team on a live map.

Install and set up

  1. Tap Download for Android, then open the file when it finishes.
  2. If Android asks, allow your browser to install unknown apps, then tap Install.
  3. Open SLG FieldTrack. The server address is already filled in.
  4. Enter the 8-character pairing code your supervisor gives you and tap Pair Device.
  5. Staff: turn on Share my location and choose Allow all the time when asked.
Your location is shared only while you keep sharing on, or when you approve a specific request. A notification stays visible the whole time, and you can pause it in the app at any moment.
